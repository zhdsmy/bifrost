# Bifrost v0.2.4

Bifrost is an unofficial Tailscale plugin for the KoolCenter / Koolshare software center. It is not affiliated with, endorsed by, or sponsored by Tailscale Inc.

## Changed

- Buttons are sized by their role, the same way as in po0fw.
  - Main actions use the default size: the overview status card actions (Enable, Connect, Disable, Re-authenticate, Log out, Migrate & Switch, Open Core tab), the migrate card button, and the advertised-routes save button. They were small before.
  - Helper actions (refresh and copy logs, jump to another tab, reset column widths), device-table actions, and confirmation popovers stay small.
- Card headers center their actions against the title and description instead of aligning them to the top.
- On narrow widths, the header icon stays next to the first line of the title instead of moving to the middle of a wrapped description.

The router scripts are unchanged from v0.2.3. Only the page changed.

## Included core

- Unchanged: Tailscale core `v1.104.7`, published as `core-1.104.7-2`.
- Packages: `hnd` and `hnd-arm64` carry the uncompressed core (the default). `hnd-upx` and `hnd-arm64-upx` carry a UPX core. Pick the package with the core type you use: an offline package replaces an installed core with the same serial.

## Tested hardware and firmware

ASUS RT-AX86U running Asuswrt-Merlin `388.12_2`, with an `hnd` package built locally from the same code as this release:

- The offline upgrade from v0.2.3 restarted the daemon once. The daemon came back with the same devices, and the status check passed.
- The router page file points to the new page assets, and the old assets were removed.
- The header, card headers, and button sizes were checked in the local preview at 1280 px and 420 px wide. They were not checked in a browser on the router page.

## Not tested

- `arm64` packages on hardware.

## Verify downloaded files

Download `SHA256SUMS`, `SHA256SUMS.sig`, and the public key from `plugin/bifrost/keys/` at this release tag. Verify the signature first, then the package hash. The checksums and commands follow at the end of these notes.
