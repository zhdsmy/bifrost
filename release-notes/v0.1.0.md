# Bifrost v0.1.0

Bifrost is an unofficial Tailscale plugin for the KoolCenter / Koolshare software center. It is not affiliated with, endorsed by, or sponsored by Tailscale Inc.

## Included core

- Tailscale core `v1.104.7`, published as `core-1.104.7-1`.
- The default package ships the signed, reproducibly built `arm` core. An `arm64` package is published only when the matching core release includes an `arm64` asset.

## Tested hardware and firmware

- ASUS RT-AX86U running Asuswrt-Merlin `388.12_2` with the `ASUSWRT` skin.
- Tested on this device and firmware: installation, upgrade, uninstall, original-plugin migration, automatic migration rollback, firewall rebuild, MagicDNS forwarding, daemon watchdog restart, router reboot, and system-log events.
- The container integration suite covered headscale `v0.29.7`.

## Not tested

- Weekly PPPoE redial behavior.
- A live router-side core update after the first public core release.
- The `ROG`, `TUF`, and `TS` firmware skins on physical hardware.

## Migration and rollback

1. Install Bifrost without enabling it.
2. Open Bifrost and click **Migrate & Switch**. Migration records the original device identity, backs up existing Bifrost state, stops the original plugin through its own script, disables its boot auto-start, copies the state files read-only, starts Bifrost, verifies that the identity matches, and rebuilds the firewall to remove leftover NAT rules.

- **Automatic rollback**: If verification fails, Bifrost stops and disables itself, restores its backup, and re-enables and starts the original plugin.
- **Manual rollback**: Disable Bifrost in its UI, then re-enable the original plugin in its own page.

## Verify downloaded files

Download `SHA256SUMS`, `SHA256SUMS.sig`, and the public key from `plugin/bifrost/keys/` at this release tag. Verify the signature first, then the package hash. The checksums and commands follow at the end of these notes.
