# Bifrost v0.1.0

Bifrost is an unofficial Tailscale plugin for the KoolCenter / Koolshare software center. It is not affiliated with, endorsed by, or sponsored by Tailscale Inc.

## Included core

- Tailscale core `v1.104.7`, published as `core-1.104.7-1`.
- The package contains the signed, reproducibly built `arm` core. An `arm64` package is published only when the matching core release contains an `arm64` asset.

## Tested hardware and firmware

- ASUS RT-AX86U running Asuswrt-Merlin `388.12_2` with the `ASUSWRT` skin.
- Installation, upgrade, uninstall, original-plugin migration, automatic migration rollback, firewall rebuild, MagicDNS forwarding, daemon watchdog restart, router reboot, and system-log events were tested on that device and firmware.
- Headscale `v0.29.7` was covered by the container integration suite.

## Not tested

- Weekly PPPoE redial behavior.
- A real router-side core update after the first public core release.
- The `ROG`, `TUF`, and `TS` firmware skins on physical hardware.

## Migration and rollback

Install Bifrost without enabling it. **Migrate & Switch** records the original identity, backs up Bifrost state, stops the original plugin through its own script, disables its boot auto-start, copies the state files read-only, starts Bifrost, verifies the identity, and rebuilds the firewall to remove leftover NAT rules. If verification fails, Bifrost stops, restores its backup, and re-enables and starts the original plugin. To switch back manually, disable Bifrost and re-enable the original plugin in its own page.

## Verify downloaded files

Download `SHA256SUMS`, `SHA256SUMS.sig`, and the public key from `plugin/bifrost/keys/` at the same source revision. Verify the signature first, then verify the package hash.

```sh
pubkey=plugin/bifrost/keys/release-1.pub.pem
openssl dgst -sha256 -verify "$pubkey" \
  -signature SHA256SUMS.sig SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS  # Linux
shasum -a 256 -c --ignore-missing SHA256SUMS  # macOS
```
