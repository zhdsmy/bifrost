# Bifrost v0.2.6

Bifrost is an unofficial Tailscale plugin for the KoolCenter / Koolshare software center. It is not affiliated with, endorsed by, or sponsored by Tailscale Inc.

## Changed

- Settings: each Save button is enabled only when its value differs from the stored one.
  - The Save button for advertised routes is a secondary button like the others.
  - The routes description no longer starts with "when enabled", since the list is not a switch.
- Yes/no and on/off values are status badges, and names and numbers are text, on every tab.
  - "Not advertised" for the exit node on the Overview tab and "mapping varies by destination" on the Diagnostics tab are now badges.
  - The preferred DERP region on the Diagnostics tab is text with its latency, as on the Overview tab.
- Diagnostics: "JFFS free space" is now "plugin storage free space". It has always measured the partition that holds `/koolshare`, which is a USB disk on some routers.
- Overview: a device whose key never expires shows "Never" instead of "—".
- Devices: a peer without a WireGuard handshake yet shows "Not yet" instead of "Never". Idle peers have no handshake.
- Core tab: the build revision no longer shows the internal serial number (`r2 (#2)` is now `r2`).
- The copied diagnostics show the router's local time and offset next to the epoch seconds.

## Fixed

- The folded list of omitted features on the Core tab, and the advanced login options, no longer draw a second line on the left inside their box.
- Password managers no longer offer to fill the router login into the auth key field of the login card.

## Included core

- Unchanged: Tailscale core `v1.104.7`, published as `core-1.104.7-2`.
- Packages: `hnd` and `hnd-arm64` carry the uncompressed core (the default). `hnd-upx` and `hnd-arm64-upx` carry a UPX core. Pick the package with the core type you use: an offline package replaces an installed core with the same serial.

## Tested hardware and firmware

ASUS RT-AX86U running Asuswrt-Merlin `388.12_2`, with the core on USB storage (ext4), and an `hnd` package built locally from the same code as this release:

- The offline upgrade from v0.2.5 restarted the daemon once. The daemon came back with the same devices, the status check passed, and the previous core backup was kept.
- Every tab was checked in Chrome on the router page in dark mode, and the Overview and Diagnostics tabs also in light mode: the key expiry, handshake, Save buttons, build revision, folded list, badges, the preferred DERP region after a network check, and the time line of the copied diagnostics.

## Not tested

- `arm64` packages on hardware.
- The English page on hardware. Page tests cover both languages.
- The auth key field with a password manager on hardware: the login card shows only when the router is logged out. Page tests check the attributes that password managers read.

## Verify downloaded files

Download `SHA256SUMS`, `SHA256SUMS.sig`, and the public key from `plugin/bifrost/keys/` at this release tag. Verify the signature first, then the package hash. The checksums and commands follow at the end of these notes.

`LICENSE` (Bifrost) and `LICENSE.tailscale` (bundled core) are attached to this release. Each package also contains both licenses, `NOTICE.md`, and `THIRD_PARTY_NOTICES.core.md` for the core's dependencies.
