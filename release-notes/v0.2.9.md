# Bifrost v0.2.9

Bifrost is an unofficial Tailscale plugin for the KoolCenter / Koolshare software center. It is not affiliated with, endorsed by, or sponsored by Tailscale Inc.

## Changed

- Text on every tab balances its last line. A description no longer ends with one word ("console.") or one Chinese character ("希。") alone. Browsers without `text-wrap: pretty` wrap as before.
- English UI: the route status "Awaiting approval" uses sentence case, like the other status values.
- The out-of-space error for a core update names plugin storage instead of JFFS, as the Diagnostics tab has since v0.2.6.
- The README screenshots show the current page.

## Fixed

- The environment check also reports a changed `--snat-subnet-routes` (`NoSNAT`). The daemon already restored it with the other three fixed settings, but the Overview tab did not warn about it.

## Included core

- Unchanged: Tailscale core `v1.104.7`, published as `core-1.104.7-2`.
- Packages: `hnd` and `hnd-arm64` carry the uncompressed core (the default). `hnd-upx` and `hnd-arm64-upx` carry a UPX core. Pick the package with the core type you use: an offline package replaces an installed core with the same serial.

## Tested hardware and firmware

ASUS RT-AX86U running Asuswrt-Merlin `388.12_2`, with the core on USB storage (ext4), and an `hnd` package built locally from the same code as this release (only the version number differs):

- The offline upgrade restarted the daemon once. The daemon came back running with no health warnings. The router kept its tag, and its advertised route stayed active.
- The page was checked in Chrome on the router: all five tabs in Chinese and dark mode; Devices, Settings, and Diagnostics in English; Overview in English and light mode. The four descriptions that ended with one word or character on a desktop-width page now carry the previous word to their last line.

## Not tested

- The `NoSNAT` warning on hardware. It is covered by the shell tests.
- The page on a narrow screen on hardware.
- The ISP's weekly PPPoE redial and a router reboot with v0.2.1 or later.
- `arm64` packages on hardware.

## Verify downloaded files

Download `SHA256SUMS`, `SHA256SUMS.sig`, and the public key from `plugin/bifrost/keys/` at this release tag. Verify the signature first, then the package hash. The checksums and commands follow at the end of these notes.

`LICENSE` (Bifrost) and `LICENSE.tailscale` (bundled core) are attached to this release. Each package also contains both licenses, `NOTICE.md`, and `THIRD_PARTY_NOTICES.core.md` for the core's dependencies.
