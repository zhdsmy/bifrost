# Bifrost v0.2.0

Bifrost is an unofficial Tailscale plugin for the KoolCenter / Koolshare software center. It is not affiliated with, endorsed by, or sponsored by Tailscale Inc.

## Included core

- Tailscale core `v1.104.7`, published as `core-1.104.7-2`. Its uncompressed cores are byte-identical to `core-1.104.7-1`; revision 2 only adds the UPX assets.
- Packages: `hnd` and `hnd-arm64` carry the uncompressed core (the default). `hnd-upx` and `hnd-arm64-upx` carry a UPX core. A package is published only when the core release has the matching asset.

## Optional UPX core

The UPX core is built with `upx 5.3.0 --best --no-lzma`. The `arm` core file is 7.7 MB instead of 25.1 MB. JFFS already compresses files, so the space you save is smaller than that difference.

The cost: each CLI call takes about 0.33 s on an RT-AX86U instead of 0.02 s, and every process decompresses its own copy into memory that cannot be shared. Use it only when the core does not fit. You can switch between the two types on the **Core** tab at any time; the switch uses the same signed download, test, swap, and rollback steps as a core update.

## Update checks

- When you open the page and the last check is more than 24 hours old, Bifrost checks for updates in the background. A failed check shows no error. The result is kept on JFFS, so it survives a reboot.
- A new core is shown on the **Core** tab. Bifrost never installs it on its own.
- A new plugin version is shown with a link to its release page. Install it from a software-center offline package as before.

## Compatibility

- v0.1.0 reads the new core manifest and updates to the uncompressed core. UPX files are listed in a new top-level `upx_assets` field, which v0.1.0 ignores.
- Installing an offline package replaces the installed core when the package core has the same or a newer serial, so the package's architecture and core type apply. An identical core is not written again.

## Verify downloaded files

Download `SHA256SUMS`, `SHA256SUMS.sig`, and the public key from `plugin/bifrost/keys/` at this release tag. Verify the signature first, then the package hash. The checksums and commands follow at the end of these notes.

`LICENSE` (Bifrost) and `LICENSE.tailscale` (bundled core) are attached to this release. Each package also contains both licenses, `NOTICE.md`, and `THIRD_PARTY_NOTICES.core.md` for the core's dependencies.
