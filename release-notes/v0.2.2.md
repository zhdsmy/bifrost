# Bifrost v0.2.2

Bifrost is an unofficial Tailscale plugin for the KoolCenter / Koolshare software center. It is not affiliated with, endorsed by, or sponsored by Tailscale Inc.

## Changed

- Devices tab: each column now has a set width (per language), and the headers are smaller. Long device names and MagicDNS names stay on one line and end with an ellipsis; hover to see the full name. Before, names broke at every hyphen.
- Devices tab: you can change column widths. Drag a column edge in the header, or focus it and press the left or right arrow key. Double-click an edge to reset that column. The widths are kept in the browser. "Reset column widths" restores the defaults.
- Devices tab: the action column widens while a ping result is shown, so the result stays on one line.
- Diagnostics tab: DERP latencies are a compact list instead of a two-column table. Each region shows its code, a latency bar and the time in ms, in up to three columns. All bars use one scale, from 0 to the slowest region. The preferred region is highlighted. At most 10 rows show; the rest scroll inside the list.

The router scripts are unchanged from v0.2.1. Only the page changed.

## Included core

- Unchanged: Tailscale core `v1.104.7`, published as `core-1.104.7-2`.
- Packages: `hnd` and `hnd-arm64` carry the uncompressed core (the default). `hnd-upx` and `hnd-arm64-upx` carry a UPX core. Pick the package with the core type you use: an offline package replaces an installed core with the same serial.

## Tested hardware and firmware

ASUS RT-AX86U running Asuswrt-Merlin `388.12_2`, with a test package built from the same page code:

- The offline install restarted the daemon once. The daemon came back with the same devices, and the firewall check passed.
- The Devices and Diagnostics tabs were checked in a browser on the router page.

## Not tested

- Resizing columns by touch. The automated browser tests drag with a mouse and use the arrow keys.
- `arm64` packages on hardware.

## Verify downloaded files

Download `SHA256SUMS`, `SHA256SUMS.sig`, and the public key from `plugin/bifrost/keys/` at this release tag. Verify the signature first, then the package hash. The checksums and commands follow at the end of these notes.
