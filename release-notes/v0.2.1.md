# Bifrost v0.2.1

Bifrost is an unofficial Tailscale plugin for the KoolCenter / Koolshare software center. It is not affiliated with, endorsed by, or sponsored by Tailscale Inc.

## Fixed

- The router admin page could not be opened over the tailnet for up to 2 minutes after the daemon started. Bifrost applied the firewall before the core knew its tailnet address, so the two DNAT rules for the admin page were missing until the next watchdog run. The system log then showed `fw: firewall rules missing (rules or settings changed); ... re-applied`. This happened after a restart, a core update, or an upgrade, whenever the core had no cached network map. The start sequence now waits up to 10 seconds for the first network map, then applies the firewall.

## Included core

- Unchanged: Tailscale core `v1.104.7`, published as `core-1.104.7-2`.
- Packages: `hnd` and `hnd-arm64` carry the uncompressed core (the default). `hnd-upx` and `hnd-arm64-upx` carry a UPX core. Pick the package with the core type you use: an offline package replaces an installed core with the same serial.

## Tested hardware and firmware

ASUS RT-AX86U running Asuswrt-Merlin `388.12_2`:

- Before the fix, a daemon restart without a cached network map left both DNAT rules out until the next watchdog run, which logged the event above.
- With the fix, the same restart waited about 2 seconds, installed both rules at once, and the next watchdog run logged no firewall event.

## Not tested

- A router reboot with this release. When control cannot be reached, the start waits the full 10 seconds before it applies the firewall.
- `arm64` packages on hardware.
