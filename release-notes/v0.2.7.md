# Bifrost v0.2.7

Bifrost is an unofficial Tailscale plugin for the KoolCenter / Koolshare software center. It is not affiliated with, endorsed by, or sponsored by Tailscale Inc.

## Changed

- English UI: buttons, links, card titles, and field labels use title case throughout.
  - "Log out", "Open Core tab", "Log in to your tailnet", "Reset column widths", and the build recipe labels on the Core tab were the exceptions.
  - Confirmation questions, status values, and descriptions keep sentence case.

## Fixed

- Logging out no longer clears the advertised routes, exit node, accepted routes, and device name.
  - `tailscale logout` replaces the profile with a new one that has default settings, and the next login used those defaults.
  - Bifrost now saves the four settings before logout and sets them on the new profile. It sets them again after each daemon start, because that profile is not saved until login. The next login uses them.
  - A change on the Settings tab while logged out replaces the saved value.
- After logging out, the Overview tab no longer briefly shows "fixed settings drifted". The fixed settings are set on the new profile right away instead of at the next watchdog check.
- Devices tab: the OS column is wide enough for "windows" and "android". The English Handshake header no longer runs into the fade of the pinned Action column on a router-width page. Widths you set yourself are kept.
- Confirmation popovers balance their lines, so a Chinese sentence no longer leaves one character ("断。") alone on its last line.
- Settings: the unchecked "Advertise router LAN subnet" checkbox has a visible border in dark and light mode. Its border was about 1.2:1 against the card and is now about 4:1.

## Logging out and tags

An interactive login after a logout makes the router a device of the account that authorizes it. Its tags are removed, so the access rules for untagged devices apply, and its key expires again (tagged devices have key expiry disabled by default). Set the tags again in the admin console after the login, or log in with a tagged auth key. This is how the control server handles the login; Bifrost does not change tags.

## Included core

- Unchanged: Tailscale core `v1.104.7`, published as `core-1.104.7-2`.
- Packages: `hnd` and `hnd-arm64` carry the uncompressed core (the default). `hnd-upx` and `hnd-arm64-upx` carry a UPX core. Pick the package with the core type you use: an offline package replaces an installed core with the same serial.

## Tested hardware and firmware

ASUS RT-AX86U running Asuswrt-Merlin `388.12_2`, with the core on USB storage (ext4), and an `hnd` package built locally from the same code as this release:

- The offline upgrade from v0.2.6 restarted the daemon once. The daemon came back running with the same advertised route, accepted routes, and no health warnings.
- The page was checked in Chrome on the router: the Devices tab in English and Chinese, the confirmation popovers, and the checkbox in dark and light mode.
- A logout and a new interactive login were done with an earlier build of this release, before the logout fix. That run found the lost settings.

The logout fix is covered by the container integration tests: against headscale and the real core, they set the device name and accepted routes, log out, restart the daemon, log in again, and check the settings at each step.

## Not tested

- The logout fix on hardware. It was not repeated on the router, because a logout needs a new authorization in the browser.
- `arm64` packages on hardware.

## Verify downloaded files

Download `SHA256SUMS`, `SHA256SUMS.sig`, and the public key from `plugin/bifrost/keys/` at this release tag. Verify the signature first, then the package hash. The checksums and commands follow at the end of these notes.
